## 🎯 Objetivo del Proyecto

Demostrar dominio técnico completo del stack requerido por Change Dyslexia mediante una plataforma educativa funcional que integre:

- ✅ **Detección temprana** de dislexia
- ✅ **Juegos terapéuticos** adaptativos
- ✅ **Dashboard analítico** para seguimiento
- ✅ **Accesibilidad** optimizada para dislexia
- ✅ **Arquitectura escalable** y mantenible

## 🧭 Navegación Rápida

- **Landing**: `apps/landing/` - Astro + Tailwind + DaisyUI
- **Dashboard**: `apps/dashboard/` - Angular + RosenCharts
- **API**: `apps/api/` - Symfony + MySQL (próximo)
- **Juegos**: `apps/games/` - Phaser.js + Unity (próximo)
- **Mobile**: `apps/mobile/` - Capacitor (próximo)
