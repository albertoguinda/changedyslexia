# 🧠 Cognitive PlayKit

Demo técnico completo desarrollado para **Change Dyslexia** que demuestra dominio del stack tecnológico requerido mediante una plataforma educativa funcional.

## 🎯 Qué es

Plataforma educativa gamificada que integra:

- ✅ **Detección temprana** de dislexia
- ✅ **Juegos terapéuticos** adaptativos
- ✅ **Dashboard analítico** para seguimiento
- ✅ **Accesibilidad** optimizada para dislexia
