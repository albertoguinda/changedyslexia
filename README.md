## ✨ ¿Qué es Cognitive PlayKit?
**Cognitive PlayKit** es una plataforma educativa gamificada desarrollada como prueba técnica para **Change Dyslexia**.  

El proyecto combina:
- **Landing Page** → construida en **Astro + Tailwind + DaisyUI + GSAP**, accesible, rápida y con animaciones sutiles.  
- **Dashboard Web** → hecho con **Angular + Tailwind + Rosen Charts**, para que profesores y administradores vean el progreso de los niños con gráficas limpias y modernas.  
- **Backend real** → desarrollado en **Symfony + MySQL**, gestionando usuarios, sesiones de juego y estadísticas.  
- **Juegos Educativos** → creados en **Phaser (2D)** y un prototipo en **Unity (3D)**, basados en ejercicios de psicología y pedagogía.  
- **Aplicación móvil híbrida** → empaquetada con **Capacitor** y soporte **PWA**, instalable en Android/iOS y usable offline.  

---

## 🎮 Los juegos
1. **Sílabas** → conciencia fonológica.  
2. **Palabras espejo** → discriminación visual.  
3. **Orden correcto** → memoria de trabajo y ortografía.  
4. **Prototipo Unity (Spatial Navigator)** → ejemplo 3D escalable.  

---

## 🛠️ Stack Tecnológico

### Frontend
- **Astro** → Landing estática ultrarrápida.  
- **Angular** → Dashboard dinámico y escalable.  
- **TailwindCSS + DaisyUI** → estilos rápidos, accesibles y consistentes.  
- **GSAP** → animaciones fluidas y profesionales.  
- **Rosen Charts** → visualización moderna de datos de progreso.  

### Backend
- **Symfony + MySQL** → API REST real para usuarios, sesiones y estadísticas.  

### Juegos
- **Phaser (TS)** → minijuegos educativos en navegador.  
- **Unity (C#)** → prototipo 3D exportable.  

### Mobile
- **Capacitor** → app híbrida empaquetada.  
- **PWA** → soporte offline.  

### Accesibilidad
- **Fuente OpenDyslexic**, **modo alto contraste** y **feedback positivo**.
