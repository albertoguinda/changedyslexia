# 📊 Dashboard - Cognitive PlayKit

Panel administrativo para seguimiento de progreso en niños con dislexia.

## 🛠️ Tecnologías

- **Angular 18** - Framework principal
- **TailwindCSS + DaisyUI** - Estilos y componentes
- **RosenCharts** (adaptados) - Visualización de datos
- **TypeScript** - Tipado estático
- **RxJS** - Manejo de estado reactivo

## 🚀 Desarrollo

### Instalación

```bash
npm install
Servidor de desarrollo
bashng serve
Navegar a http://localhost:4200
Build de producción
bashng build --configuration=production
🏗️ Estructura
src/app/
├── core/                 # Servicios y guards
├── shared/              # Componentes compartidos
├── features/            # Módulos de funcionalidades
│   ├── auth/           # Login y registro
│   ├── dashboard/      # Panel principal
│   └── profile/        # Configuración usuario
♿ Accesibilidad

Fuente OpenDyslexic opcional
Modo alto contraste
Navegación por teclado
Compatible con screen readers
```
