# Cognitive PlayKit - Change Dyslexia Demo

Bienvenido al proyecto **Cognitive PlayKit**, una plataforma educativa diseñada como **prueba técnica para Change Dyslexia**.  
Este proyecto busca demostrar habilidades técnicas, capacidad de organización y compromiso social, **alineando el desarrollo de software con la misión de ayudar a niños con dislexia a alcanzar sus sueños**.

---

## 🌍 Visión
Más que una demo técnica, esta aplicación es una **primera impresión insuperable**: una landing clara y accesible, juegos interactivos que entrenan habilidades cognitivas clave, y un dashboard para seguir el progreso.

Cada parte del proyecto está pensada para que Change Dyslexia vea que:
1. **Domino el stack que piden en la oferta**.
2. **Sé organizar proyectos completos** en poco tiempo.
3. **Comprendo la importancia social del trabajo**.

---

## 📦 Qué incluye
- **Landing Page** (Astro + Tailwind)  
  Presentación de Change Dyslexia, explicación de la dislexia, propuesta de valor de la app y CTA hacia juegos y dashboard.  
  ➝ La primera impresión debe ser **inolvidable**: tipografía clara, accesibilidad, animaciones sutiles.

- **Dashboard Web** (Angular + Tailwind)  
  Panel para administradores/profesores con usuarios, juegos y estadísticas de progreso.

- **Backend API** (Symfony + MySQL)  
  Gestión de usuarios, sesiones de juego y progreso. Backend real, no simulado.

- **Juegos Educativos** (Phaser y Unity)  
  Mini-juegos diseñados con base en psicología y pedagogía:
  - **Sílabas** → conciencia fonológica  
  - **Palabras espejo** → discriminación visual  
  - **Orden correcto** → memoria de trabajo y ortografía  

- **Aplicación Móvil** (Capacitor)  
  Empaquetado de la plataforma en app híbrida con soporte offline.

---

## 🎯 Objetivo
Al final del proyecto se entrega:
- 🌐 **URL en producción (Vercel)** con landing, dashboard y juegos.  
- 📱 **App móvil instalable**.  
- 📖 **Repositorio GitHub documentado** con código limpio, comentarios en español y buenas prácticas.  

Este trabajo refleja **adaptabilidad tecnológica** y **sensibilidad social**, dos cualidades clave para formar parte de Change Dyslexia.
