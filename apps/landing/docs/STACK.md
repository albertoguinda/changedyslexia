# Stack Tecnológico

Este proyecto utiliza un stack cuidadosamente elegido para cumplir con los requisitos de la oferta de Change Dyslexia y, al mismo tiempo, aportar valor real a la experiencia de los niños y profesores.

---

## Frontend

### Astro
- **Por qué**: framework ligero y rápido para sitios estáticos.  
- **Para qué**: crear una **Landing Page** impecable, optimizada y accesible.

### Angular
- **Por qué**: framework robusto que demuestra experiencia en entornos empresariales.  
- **Para qué**: construir el **Dashboard administrativo**, con vistas dinámicas y gráficas.

### TailwindCSS + DaisyUI
- **Por qué**: prototipado rápido, accesibilidad, consistencia visual.  
- **Para qué**: asegurar una interfaz limpia y profesional en **Landing + Dashboard**.

---

## Backend

### Symfony + MySQL
- **Por qué**: está en la oferta, es estándar en Europa y muy sólido.  
- **Para qué**: construir una **API REST real** para usuarios, juegos y progreso.

Endpoints previstos:
- `POST /api/auth/login`  
- `GET /api/users/profile`  
- `POST /api/games/session`  
- `GET /api/progress/stats`

---

## Juegos

### Phaser (TS)
- **Por qué**: motor ligero para juegos 2D en navegador.  
- **Para qué**: crear juegos directamente jugables en la web.

### Unity
- **Por qué**: motor AAA, demuestra flexibilidad en stacks distintos.  
- **Para qué**: prototipo exportable que muestre visión a futuro (ej. juego 3D sencillo).

---

## Mobile

### Capacitor
- **Por qué**: facilita llevar cualquier web a app móvil nativa.  
- **Para qué**: empaquetar la plataforma y mostrarla como aplicación instalable.

---

## Extra

### GSAP
- **Por qué**: animaciones profesionales y fluidas.  
- **Para qué**: dar vida a la landing y a transiciones clave (impacto visual).  

### Accesibilidad
- **OpenDyslexic Font** y modos de alto contraste.  
- **Para qué**: experiencia optimizada para niños con dislexia.
